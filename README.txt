BIRTHDAY SURPRISE WEBSITE — BLESSINGS MARY

Files:
- index.html: the complete birthday website (HTML, CSS and JavaScript are all inside this file).
- dont-let-go-zavyre.mp3: the supplied “Don’t Let Go” song by Zavyre.

IMPORTANT: Keep index.html and dont-let-go-zavyre.mp3 together in the same folder.

To test: open index.html in a browser and tap “Play our song” if autoplay is blocked.
Browsers commonly block audio autoplay until the visitor interacts with the page.

To publish with GitHub Pages: upload BOTH files to the root of the repository, commit the changes, and enable Pages from the main branch / root folder.
